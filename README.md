# App Ed. Marapendi · telas (TESTE)

Telas do app do condomínio Ed. Marapendi, publicadas pelo GitHub Pages.

- Este repositório é **público** e não contém senhas nem dados de moradores.
- Os dados ficam no servidor (Google Apps Script) e numa planilha privada da conta do condomínio.
- `config.js` diz qual servidor usar. Versão atual: 0.4.0.

Arquivos: `index.html` (página), `app.css` (visual), `app.js` (telas), `servidor.js` (comunicação com o servidor), `config.js` (configuração), `logo.jpg`.
